# Звезда родилась

Четыре страницы по макетам Figma. Чистый HTML, один общий `index.css`, flexbox и БЭМ. Сборка, npm и JavaScript не нужны.

## Открыть

Откройте `profile.html` в браузере. Нажатие на карточку «Оценить» открывает `mark.html`. Остальные страницы открываются отдельно:

- `profile.html` — профиль участника;
- `mark.html` — выбор оценки от 1 до 10;
- `jury.html` — оценки пяти судей;
- `result.html` — общий балл 44.

При желании можно запустить локальный сервер из этой папки:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Затем открыть <http://127.0.0.1:8080/profile.html>.

## Как устроено

Из предыдущей работы сохранены простая структура HTML, разделение CSS на блоки, БЭМ с модификаторами через одно подчёркивание и пропорциональный масштаб через CSS-переменную. Общие элементы оформлены блоками `info`, `photo`, `sparkle`, `footer`; отдельные — `profile`, `scores`, `jury`, `total`.

На широком экране сохраняются пропорции макетов: 1194×834 для планшета и 5120×1792 для сцены. Масштаб учитывает и ширину, и высоту окна; свободное место остаётся фоном. До 600 px включается вертикальная компоновка. Основные блоки расположены flexbox; абсолютное позиционирование используется только для декора, кадрирования фотографий и служебных элементов.

Все изображения, SVG и шрифты находятся в `assets/`. Фотографии и фон взяты из макета; внешних запросов при открытии страниц нет. Исходная работа в `example/` не изменена.

Оценки — нативные радиокнопки: работают мышь, касание, Tab и стрелки, предусмотрен видимый фокус. Изначально выбран балл 8, как в макете. Это статическая вёрстка: выбор не отправляется на сервер, а страницы жюри и результата показывают данные макета. Кнопку отправки, которой нет в указанном макете `6021:208`, не добавляли.
